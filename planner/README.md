# מרחב · Life Planner

מערכת אישית לניהול משימות, פרויקטים, מטרות, הרגלים ותכנון שבועי — עברית RTL מלא, עיצוב פרימיום.

זהו פרויקט **נפרד** מאפליקציית האימונים (AMONTY / `components/TrainApp.tsx`) ואינו נוגע בה.

## סטטוס — שלב "ליבה" (Preview)

הליבה בנויה כקובץ HTML עצמאי אחד (`index.html`) עם **מסד נתונים מרכזי אחד** ב-`localStorage`
(`state.tasks` / `state.inbox`). כל התצוגות קוראות וכותבות לאותו מקור — שינוי בכל מקום משתקף מיד בכל המערכת.

### מה פעיל
- **בית / Dashboard** — ברכה + תאריך, 5 כרטיסי KPI לחיצים (להיום / באיחור / פתוחות / הושלמו היום / מחכה לאחרים),
  "הפוקוס שלי היום", ווידג'טים: מחכה לאחרים, 7 ימים קרובים, הרגלים.
- **משימות** — מאגר מרכזי, סינון לפי טקסט/סטטוס/תחום, קיבוץ (באיחור/היום/בהמשך/ממתין/הושלם),
  פעולות מהירות (סיום, עריכה, דחייה, המתנה, מחיקה).
- **Quick Add** — חלון מהיר עם שדה חופשי + פירוק שפה טבעית בעברית (מחר / ביום חמישי / ב-10:00 / דחוף / תחום),
  עם אפשרות תיקון לפני שמירה.
- **Inbox** — קליטה מהירה; המרה למשימה / פרויקט / רעיון / הערה.
- **השבוע שלי** — 7 ימים RTL (ראשון מימין, שבת משמאל), גרירה בין ימים משנה את תאריך היעד.
- **פרויקטים** — כרטיסים עם התקדמות אוטומטית (מחושבת ממשימות הפרויקט), ספירת פתוחות/בוצעו/באיחור,
  "פעולה הבאה" מודגשת + התראה על פרויקט פעיל בלי פעולה הבאה, קישור למטרה, מעבר למשימות הפרויקט.
- **מטרות (קסקדה)** — מטרות שנתיות/רבעוניות/חודשיות. כל מטרה מתפרקת ליעדי משנה ולפרויקטים מקושרים,
  עם התקדמות מתגלגלת (מדד ידני, או ממוצע יעדי המשנה/הפרויקטים). מדגים את השרשרת מטרה → פרויקט → משימה.
- **הרגלים** — Habit Tracker ויזואלי: רצף נוכחי + שיא, אחוז שבועי (מול יעד), ספירה חודשית,
  סימון יומי בלחיצה לשבוע הנוכחי, הוספה/עריכה/מחיקה. ווידג'ט חי גם בדשבורד.
- **לולאת היום** — שלושה טקסים מהדשבורד:
  - 🌅 **פתיחת יום** — 3 המשימות החשובות, מה באיחור, מעקבים לחזור אליהם, והרגלים לסימון מהיר.
  - 🌙 **סגירת יום** — מה בוצע היום, ולכל משימה שלא הושלמה: מחר / שבוע הבא / ממתין / ביטול / "בעצם סיימתי". אין דחייה אוטומטית.
  - 📋 **סקירה שבועית** — נוצרו/בוצעו/נדחו/פתוחות/באיחור, התחום העמוס, התקדמות מטרות, עקביות הרגלים, ו-3 שאלות רפלקציה שנשמרות.
- מצב כהה/בהיר, פלטה רגועה ("quiet/premium"), רספונסיבי מלא למובייל, RTL נשמר בכל מצב.

### מה עדיין לא (מודולים הבאים)
ביצועים/Analytics · הגדרות · מנוע משימות חוזרות מלא · WhatsApp/Calendar/AI — ומעל הכל: **מעבר לשרת/DB** (סנכרון בין מכשירים).

### מה זה עדיין לא, טכנית
`localStorage` בלבד — אין שרת/DB, אין סנכרון בין מכשירים, אין WhatsApp/Calendar אמיתיים.
כל אלה שלב הבא, על בסיס אותו מודל נתונים.
